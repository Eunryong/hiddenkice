# Supabase CSV Data Fields

이 문서는 Supabase에 CSV를 import할 때 각 필드에 어떤 데이터가 들어가는지 정리한 문서입니다.

## CSV 파일

- `textbooks.csv`: `textbooks` 테이블에 넣을 교재 목록 데이터
- `banners.csv`: `banners` 테이블에 넣을 교재 메인 배너 데이터

## textbooks

교재 카드와 목록 필터에 사용되는 기본 교재 데이터입니다.

| 필드명 | 타입 | 필수 | 예시 | 설명 |
| --- | --- | --- | --- | --- |
| `id` | `bigint identity` | 예 | `1` | 교재를 고유하게 구분하는 ID입니다. CSV import 후 Supabase Table Editor에서 행을 쉽게 확인하고 수정할 수 있도록 CSV에 명시합니다. |
| `title` | `text` | 예 | `2026 Hidden Kice 국어 독서 기본서` | 화면의 교재 카드에 노출되는 교재명입니다. |
| `textbook_type` | `text` | 예 | `단품` | 교재 유형입니다. 현재 필터 기준은 `단품`, `패스`를 사용합니다. |
| `image_url` | `text` | 아니오 | `image/textbooks/textbook1.webp` | Supabase Storage에 업로드할 교재 표지 이미지 경로입니다. DB에는 이미지 파일이 아니라 경로만 저장합니다. |
| `original_price` | `integer` | 아니오 | `28000` | 정가입니다. 할인 전 가격을 표시할 때 사용합니다. 원 단위 숫자만 넣습니다. |
| `discount_rate` | `integer` | 아니오 | `10` | 할인율입니다. `10`은 10% 할인을 의미합니다. |
| `price` | `integer` | 예 | `25200` | 실제 판매가입니다. 클라이언트에서 계산하지 않고 DB 값을 그대로 화면에 표시합니다. |
| `display_order` | `integer` | 아니오 | `1` | 목록 노출 순서입니다. 숫자가 작을수록 먼저 보여줍니다. |
| `is_active` | `boolean` | 아니오 | `true` | 화면 노출 여부입니다. `false`면 조회 조건에서 제외할 수 있습니다. |
| `created_at` | `timestamptz` | 아니오 | `2026-06-10T00:00:00+09:00` | 데이터 등록 시점입니다. CSV에서는 고정값을 넣었고, 실제 운영에서는 Supabase 기본값 `now()`를 사용할 수 있습니다. |

테이블의 `id` 컬럼은 `generated by default as identity`로 둡니다. 그래야 일반 insert에서는 Supabase가 ID를 자동 생성하고, CSV import에서는 CSV에 있는 `id` 값을 그대로 넣을 수 있습니다.

### 현재 더미 데이터 기준

- `단품` 교재는 개별 교재 카드로 표시할 데이터입니다.
- `패스` 교재는 여러 교재를 묶은 상품처럼 표시할 데이터입니다.
- 표지 이미지는 현재 `textbook1.webp`, `textbook2.webp` 두 개를 반복 사용합니다.
- `price`는 `original_price`와 `discount_rate`로 계산 가능한 값이더라도 DB에 저장된 값을 우선합니다.

## banners

교재 목록 상단 메인 배너에 사용되는 운영 데이터입니다.

| 필드명 | 타입 | 필수 | 예시 | 설명 |
| --- | --- | --- | --- | --- |
| `id` | `bigint identity` | 예 | `1` | 배너를 고유하게 구분하는 ID입니다. CSV import 후 Supabase Table Editor에서 행을 쉽게 확인하고 수정할 수 있도록 CSV에 명시합니다. |
| `title` | `text` | 아니오 | `2026 Hidden Kice 교재 런칭 배너` | 배너의 대체 텍스트 또는 관리용 제목입니다. |
| `image_url` | `text` | 예 | `image/banner/main_banner.webp` | Supabase Storage에 업로드할 배너 이미지 경로입니다. |
| `link_url` | `text` | 아니오 | `/textbooks` | 배너 클릭 시 이동할 경로입니다. 외부 링크가 필요하면 전체 URL을 넣을 수 있습니다. |
| `display_order` | `integer` | 아니오 | `1` | 배너 노출 순서입니다. 숫자가 작을수록 먼저 보여줍니다. |
| `is_active` | `boolean` | 아니오 | `true` | 화면 노출 여부입니다. `false`면 조회 조건에서 제외할 수 있습니다. |
| `created_at` | `timestamptz` | 아니오 | `2026-06-10T00:00:00+09:00` | 데이터 등록 시점입니다. |

테이블의 `id` 컬럼은 `generated by default as identity`로 둡니다. 그래야 일반 insert에서는 Supabase가 ID를 자동 생성하고, CSV import에서는 CSV에 있는 `id` 값을 그대로 넣을 수 있습니다.

### 현재 더미 데이터 기준

- 현재 배너 데이터는 1개만 사용합니다.
- 이미지 경로는 변환된 WebP 파일 `image/banner/main_banner.webp`를 기준으로 합니다.
- Figma 시안처럼 여러 배너를 운영하려면 같은 컬럼 구조로 행을 추가하고 `display_order`를 증가시키면 됩니다.

## 이미지 경로 기준

현재 WebP 파일은 다음 경로로 준비되어 있습니다.

```txt
image/
├── banner/
│   └── main_banner.webp
└── textbooks/
    ├── textbook1.webp
    └── textbook2.webp
```

CSV의 `image_url` 값은 위 경로와 일치해야 합니다.

Supabase Storage에서 버킷명을 따로 사용하는 경우에는 프론트에서 다음 중 하나로 처리합니다.

- DB에는 현재처럼 버킷 내부 경로만 저장하고, 프론트에서 public URL을 조합합니다.
- DB에 Supabase public URL 전체를 저장합니다.

이번 데이터는 버킷 내부 경로만 저장하는 방식을 기준으로 작성했습니다.
